# Simulacros · Oracle Linux Virtualization Manager Associate 1Z0-1170

Esta carpeta contiene pruebas completas para realizar después de la formación. No
son las preguntas de repaso utilizadas durante las clases y no reproducen
preguntas reales ni material confidencial de Oracle.

## Formato utilizado

Los simulacros reproducen los datos publicados para el examen vigente:

| Elemento | Valor |
|---|---:|
| Preguntas | 50 |
| Tiempo | 90 minutos |
| Formato | elección múltiple |
| Aprobado | 68 % |
| Respuestas correctas necesarias | 34 de 50 |
| Penalización por respuesta incorrecta | no hay puntuación negativa |

Oracle puede modificar las condiciones. Antes de reservar el examen se confirma
la ficha actual de 1Z0-1170 en Oracle University.

## Instrucciones para el alumno

1. Dispone de **90 minutos** para responder las 50 preguntas.
2. Cada pregunta indica si debe seleccionar una o varias respuestas.
3. Cuando se solicitan varias respuestas, la selección solo se considera correcta
   si contiene todas las opciones correctas y ninguna incorrecta.
4. No consulte el manual, las notas ni la versión de respuestas durante el intento.
5. No hay puntuación negativa: responda todas las preguntas.
6. Marque las dudosas y reserve los últimos diez minutos para revisarlas.
7. Finalizado el tiempo, utilice la plantilla de corrección del documento de
   respuestas.

## Criterio de resultado

| Aciertos | Porcentaje | Lectura |
|---:|---:|---|
| 43–50 | 86–100 % | preparación sólida; revisar únicamente errores |
| 38–42 | 76–84 % | buen nivel, pero quedan objetivos que consolidar |
| 34–37 | 68–74 % | aprobado ajustado; no existe margen suficiente |
| 30–33 | 60–66 % | cerca del objetivo; repetir los bloques débiles |
| 0–29 | 0–58 % | volver al manual y realizar repaso por materias |

El porcentaje se calcula así:

```text
porcentaje = aciertos ÷ 50 × 100
```

## Estrategia recomendada

- Primera vuelta: responder lo evidente sin superar aproximadamente un minuto por
  pregunta.
- Segunda vuelta: resolver escenarios y preguntas de varias respuestas.
- Revisión: comprobar palabras como **siempre**, **únicamente**, **obligatoria**,
  **primero** y **mejor**.
- Corrección: no memorizar la letra. Explicar por qué las restantes opciones son
  incorrectas.
